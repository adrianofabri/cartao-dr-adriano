# Cartão digital — Dr. Adriano Fabri Domingues

Cartão de visitas responsivo, publicado no GitHub Pages.

**Acessar:** https://adrianofabri.app/

## Conteúdo

- WhatsApp das secretárias Domingues Vittalis e Sálus Clinic
- Instagram, localização e contato em vCard
- Compartilhamento nativo, WhatsApp e cópia do link

## Manutenção

Edite `index.html` para alterar textos, aparência e links, `contato.vcf` para atualizar o contato e `assets/` para imagens. Não requer instalação nem compilação.

O GitHub Pages publica a raiz da branch `main`. Alterações enviadas à branch são publicadas automaticamente.

A identidade visual e as fotografias pertencem ao respectivo titular.
